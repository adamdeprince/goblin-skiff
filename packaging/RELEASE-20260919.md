# Goblin Skiff release 20260919.2

Goblin Skiff is a fork of Mosh, optimized for bandwidth-constrained links.
This release publishes the renamed commands, configurable startup deadlines
and negotiated radio pacing. Goblin protocol remains version 1.

The packages were built from
[`04f2e1d414f8b03d1ee0ec031453b4c67a3e4078`](https://github.com/adamdeprince/goblin-skiff/commit/04f2e1d414f8b03d1ee0ec031453b4c67a3e4078).
The public Homebrew tap commit is
`d8196648abab51880fb11df5a00a2ccec02a4993`.

The skips are the optional OpenSSL FIPS-provider test where no configured
provider is available, plus disabled librsync integration in the tablet
profile. Every target has zero test failures or errors. Linux
base images are pinned by digest in each target's published `base-image.txt`.
All prebuilt packages pass the check that excludes RaptorQ.

Fresh public HTTPS installations passed on all nine targets. Linux checks
install from the signed APT or DNF repositories, retrieve matching source,
and verify package contents, encrypted file transfers and lossy four-hop
relay transfers. DNF checks enable both package and repository signature
verification. The Homebrew check installs the published bottle, confirms
`poured_from_bottle`, and passes file-transfer, relay and linkage checks.
Public tap cloning and fetching also passed.

A clean source snapshot passed `./autogen.sh`, `./configure` and `make -j8`.
Installed commands are `goblin-skiff`, `goblin-skiff-client`,
`goblin-skiff-server`, `goblin-skiffcp` and
`goblin-skiff-compile-dictionary`, with matching man pages. The packages
include the license and trademark notice. No compatibility commands or
aliases were added. Historical APT/RPM and Homebrew release archives remain immutable; active
package indexes and the Homebrew tap advertise the new package name.

Interoperability passed in both directions with upstream Mosh 1.4.0 and
with the September 15 compatibility baseline. These checks exercise wrapper
bootstrap, real PTYs, loopback UDP, keyboard input and screen output using
`--local`; they do not test external SSH authentication. The upstream
reference retains upstream source and uses distinct build output names.
Startup banners, peer-facing environment variables and protocol framing
are preserved.

The companion Goblin Modem release `0.1.0.20260919.1` updates its package
dependency, launcher commands and local configuration variables for Skiff.
Its Linux driver race tests and 11 launcher tests pass. The macOS app builds;
the published installer passes checksum, extraction, application signature
integrity, dependency and launcher checks. The app is ad hoc signed and the
installer is not notarized. The native macOS driver test suite still has
Linux device-path assumptions; the complete driver suite passed on Linux.
The live Modem app and helper were not replaced, and radio hardware was not
tested. Modem changes are published as matching source with a review diff;
the separate local Modem checkout was left untouched.

The [Inkline tablet bundle](https://inkline.goblinreactor.com/downloads/utilities/2026-09-19/)
adds an ARMv7 build for reMarkable 2 with static WebP and DjVuLibre, a private
encoder, Perl and UTF-8 locale. Physical tests on firmware 3.27.3.0 passed
installation, runtime preflight, the complete graphics regression and
upstream Mosh 1.4.0 interoperability in both directions. A Mac-to-tablet
session passed over USB using `--no-ssh-pty` for the tablet's Dropbear SSH
daemon. [Build details](inkline/README.md) and published verification logs
record the profile, inputs and results.

The tablet now has Skiff's five commands. Its superseded fork package and
four command links were removed. Inkline's download pages and installer
selector advertise Skiff; the old fork bundle, matching source and both
checksum files were removed from the public directory. Other utilities and
the separately offered upstream Mosh package were preserved. The Skiff
website also lists the tablet package.
