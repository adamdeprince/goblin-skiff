# Goblin Skiff release 20261117.1

Published release `1.4.0-goblin20261117.1` on 17 November 2026. Goblin
protocol remains **1**.

The release updates Skiff for the current Silkie protocols. Program Status
Protocol (`OSC 7501`) uses the reliable priority notice channel, ahead of
bulk screen/image/file traffic. Image handling follows the current packed,
indexed, palette and high precision format assignments, including transfer
functions, capability negotiation and rendering fallbacks. See
[CHANGELOG.md](../CHANGELOG.md) and [COMPATIBILITY.md](../COMPATIBILITY.md).

All four packages use the committed source snapshot
`945cd6de03f5ad2b2eace73e9b925d6359261df9`. This release record follows that
snapshot and does not change its build inputs. The source archive SHA-256 is
`c7b4ce77b6c602d9e19112dbe314b5afa61a978de2e60ff0964f5eebd8c81b68`.

Each target ran the 36 checks in `packaging/release-tests.txt`, with no test
failures or errors. The skip is the optional FIPS-provider check: no FIPS
provider is installed/configured. RaptorQ is excluded from every package.
The Mac run uses the current Silkie parser for terminal layout checks and
verifies all 9,702 cell images, placements, a changed tile, keyboard input
and clean shutdown.

Extracted Linux packages passed runtime linkage, encrypted file transfer
and four-hop relay checks without installing the release. An additional
naamah relay run timed out at initial display; its complete retry passed.
The Mac build also checks installed binaries in an isolated Homebrew prefix.
The finished bottle extracts successfully; its arm64 commands start, manual
pages are present and runtime linkage has no temporary build-prefix paths.
The existing Homebrew installation and opt link remain on
`1.4.0-goblin20260919.2`.

Interoperability passed both ways with the September 15 baseline
(`dbab9fe`, release `1.4.0-goblin20260915.1`), using each client's matching
wrapper. These checks exercise local wrapper bootstrap, real PTYs,
encrypted loopback UDP, keyboard input, screen output and clean shutdown.
They do not exercise external SSH authentication.

Loongson uses GCC 15.2.0's old-world ABI and bundles private runtime
libraries under `/usr/lib/goblin-skiff`, including its DjVu encoder. The
package preserves the dependency licenses and uses relative runtime library
paths. Build/finalization scripts are in `packaging/loongson/`; pinned
OpenSSL 3.5.5 and librsync 2.3.4 archives and the existing graphics dependency
sources remain in the build host's `~/skiff-release-deps/` and
`~/skiff-deps/` caches. Their recorded archive hashes accompany the package.

The release stage is
`~/goblin-deploy/goblin-skiff/1.4.0-goblin20261117.1/`.
It contains the immutable source archive, three Debian packages, the Mac
bottle and rendered Homebrew formula, build/test logs, per-host provenance,
and `SHA256SUMS`. Only this completed stage is the published release;
earlier trial stages are superseded.

The public [APT catalog](https://apt.goblinreactor.com/packages.json) and
[Homebrew catalog](https://brew.goblinreactor.com/packages.json) carry the
release, signed by the existing archive key
`B7B61E8CB85A9270530364F23273CB62402FC793`. All four public binary downloads
and both matching source downloads pass SHA-256 verification. Signed APT
index chains pass for `resolute` amd64/arm64 and `kylin` loongarch64.

The public Homebrew bottle pours successfully in an isolated prefix and
its installed binaries pass direct encrypted file-transfer and four-hop
relay checks. Homebrew's ordinary `brew test` preflight rejects the
workstation's unrelated Xcode 16.3 installation, despite the selected
current CLT. Running the formula test block directly passes its version,
manual-page, FEC-policy and file-transfer checks, but its one-hop lossy
relay check repeatedly times out at initial display. The same installed
binaries pass that relay workload outside the Homebrew test runner. This
test-environment discrepancy remains unresolved; the public formula test
block is not recorded as passing.

The public Homebrew tap includes URL correction
`72889a22f41ccda9e913e93257e262167a8c3939`: removing the trailing slash from
the bottle root prevents Homebrew from requesting a double-slash path.
The source and binary archive checksums are unchanged. The build helper
also normalizes that URL for future releases. The tap correction preserves
the concurrently published Odin release.

The [product page](https://skiff.goblinreactor.com/) advertises the four new
targets and retains older versions for the other distributions. The source
branch is published to the existing `low-bandwidth-mosh` branch in
`adamdeprince/goblin-skiff`; local remotes and historical releases are
preserved. The public-download, signature and installation verification logs
are retained under the release stage's `verification/` directory.
